# Todo Uygulaması

Bu basit Todo uygulaması, HTML, CSS ve JavaScript kullanılarak geliştirilmiştir. Kullanıcılar görevler ekleyebilir, bunları tamamlandı olarak işaretleyebilir, silebilir ve filtreleyebilirler.

## Özellikler

- Görev ekleme
- Görevleri tamamlandı olarak işaretleme
- Görev silme
- Görevleri filtreleme (Tümü, Aktif, Tamamlanan)
- Tamamlanan görevleri toplu silme
- Yerel depolama sayesinde sayfa yenilendiğinde görevlerin korunması

## Nasıl Kullanılır

1. Sayfayı tarayıcınızda açın (index.html)
2. Metin kutusuna bir görev yazın ve "Ekle" düğmesine tıklayın
3. Görevler listede görünecektir
4. Görevleri tamamlandı olarak işaretlemek için yanlarındaki onay kutusunu işaretleyin
5. Görevleri silmek için yanlarındaki ❌ simgesine tıklayın
6. Görevleri filtrelemek için üstteki filtreleme düğmelerini kullanın
7. Tüm tamamlanan görevleri silmek için "Tamamlananları Temizle" düğmesine tıklayın

## Kurulum

Herhangi bir kurulum gerekmez. Sadece dosyaları indirin ve `index.html` dosyasını tarayıcınızda açın.

```
git clone https://github.com/kullanici-adi/todo-uygulamasi.git
cd todo-uygulamasi
```

veya ZIP olarak indirerek de kullanabilirsiniz.
